Remote MCP server for Lichess

A chess coach that never makes up the chess

MCP (Model Context Protocol) lets AI apps like Claude and Cursor call outside tools. This server gives them Lichess, the free open-source chess site: your games, the mistakes its engine flagged, cloud evaluations, perfect endgame play and daily puzzles. The model explains. Lichess does the chess. No API key needed.

    what your assistant gets

    Nine tools, all read-only, each described to the model in its own words below. The descriptions are read live from the server, and every number in an answer comes from the Lichess source named under each one.

      why the model never does the chess

      Language models are fluent about chess and often wrong about it. They suggest illegal moves, miss one-move tactics, and give confident evaluations that no engine would agree with. A coach that does that teaches bad habits. So this server draws a hard line.

      Evaluations come from engines

      Per-move evals and mistake labels come from Lichess's server analysis. Position evals come from the Lichess cloud cache. Endgames with 7 pieces or fewer come from the tablebase, which is exact.

      Missing data says "not available"

      If a game was never analysed or a position isn't in the cloud cache, the tool says so and tells the model not to estimate. The model can then send you to the Lichess analysis board.

      Code only does bookkeeping

      chess.js checks that FENs are valid, replays games and turns engine notation (e2e4) into readable moves (e4). It never judges a position.
